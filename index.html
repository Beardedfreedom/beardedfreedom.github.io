what this is

A logbook for people who live in the CLI

Claude Code ships fast and quiet. New flags appear, models rotate, behaviors shift — and most of it never lands in a public changelog. This is where it gets written down.

  • Binary-grounded. Findings come from reading the actual artifact — flags, strings, native modules — not from guessing at marketing copy.
  • Version-tracked. Every issue diffs the new build against the last, so you know exactly what moved.
  • Defender-first. We publish how things work. We do not publish how to break them. (See the ethos.)
  • For builders. If you script around the CLI, hook it, or trust it in a pipeline, this is your early-warning feed.
